## 1. Mandatory Asset Provenance Policy

In strict adherence to Master Build Brief §7.5 and §10.5:
1. **Zero Copied Assets**: Under no circumstances does ShilpLoka utilize any textures, sound effects, music, or 3D models from Minecraft, Mojang, or any copyrighted commercial title.
2. **Acceptable Asset Sources**: Every single asset bundled with ShilpLoka must belong to one of three categories:
   - **Category A (Project-Original)**: Created specifically for ShilpLoka by Kanak Prabhakar or commissioned artists.
   - **Category B (Procedurally Generated)**: Synthesized at build time by automated tools in `tools/` (licensed as CC0 public domain).
   - **Category C (Permissive Open License / CC0)**: Public domain (Creative Commons CC0) or vetted open-source licenses (SIL Open Font License 1.1, MIT, Apache 2.0) with explicit attribution.
3. **Build-Time Manifest Audit**: Every asset file must have a verified entry in this document and the machine-readable asset manifest.

## 3. Procedural Asset Generation Pipeline (`tools/texture-gen`)

To ensure the game is fully playable and visually cohesive from Day 1, a procedural generator creates all $16 \times 16$ block and item textures:
- **Location**: `tools/texture-gen/generate_textures.py` (or Java utility).
- **Technique**: Controlled value-noise modulation over curated palette ramps:
  - Sandstones: Warm yellow ochre and reddish pinks.
  - Basalt: Deep columnar charcoal with subtle cool blue undertones.
  - Terracotta: Earthy burnt orange and clay tones.
  - Woods: Grain patterns tailored to each wood species (Sal, Deodar, Neem, Teak).
- **Replacement Workflow**: When hand-drawn $16 \times 16$ pixel art is completed, the artist simply overwrites the PNG files in `assets/textures/` using identical filenames, with zero code or JSON changes required.

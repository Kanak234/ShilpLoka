# Security Policy

## Supported Versions

The following versions of ShilpLoka are currently supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security and integrity of ShilpLoka seriously. If you discover a potential security vulnerability, please report it responsibly:

1. **GitHub Security Advisory (Preferred):** Submit a confidential report via GitHub's [Private Vulnerability Reporting](https://github.com/Kanak234/ShilpLoka/security/advisories/new).
2. **Email:** Reach out to the maintainers with technical details and reproduction steps.

Please provide:
- A detailed description of the vulnerability.
- Steps or a minimal script to reproduce the issue.
- Impact assessment and affected components.

### Response Timeframe
- **Initial Acknowledgement:** Within 48 hours.
- **Triage & Status Update:** Within 5 business days.
- **Fix & Disclosure:** Coordinated release and disclosure schedule.

Please avoid publicly disclosing any vulnerabilities until maintainers have had adequate time to analyze and deploy a patch.
